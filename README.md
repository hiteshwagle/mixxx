[Mixxx] is Free DJ software that gives you everything you need to perform live
DJ mixes. Mixxx works on GNU/Linux, Windows, and macOS.

## Quick Start

To get started with Mixxx:

1. For live use, [download the latest stable version][download-stable].
2. For experimentation and testing, [download a development release][download-testing].
3. To live on the bleeding edge, clone the repo: `git clone https://github.com/mixxxdj/mixxx.git`

## Bug tracker

## Documentation

<!-- Begin documentation autonomously generated by an AI agent. -->
The optional [agent backend](backend/README.md) provides a local API for track
registration, session planning, durable commands and confirmed playback state.
It runs independently of the C++ build. The opt-in native Mixxx bridge connects
the backend to real decks and controls using the documented
[protocol](backend/BRIDGE_PROTOCOL.md). The ChatGPT plugin is not yet packaged,
and Apple Music streaming is not enabled.

Start the backend first, then launch the rebuilt Mixxx with its generated config:

```shell
backend/.venv/bin/mixxx-backend --music-dir "$HOME/Music"
```

In a separate terminal at the repository root:

```shell
./build/mixxx --resource-path "$PWD/res" --settings-path "$PWD/build/user-settings" --agent-bridge "$PWD/backend/.data/mixxx-bridge.json"
```

Without `--agent-bridge`, Mixxx does not connect to the backend. Bridge commands
can change playback; use a separate development settings folder for testing.
